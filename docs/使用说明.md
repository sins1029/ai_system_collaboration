# 使用说明

## 1. 运行条件

- Windows PowerShell；Python 3.10 或更高版本。
- 项目根目录包含 `src/`、`configs/` 和 `pyproject.toml`。
- SustainCluster 参考仓库可读，但不属于主项目源码。
- MPC 需要 SciPy MILP/HiGHS；BC 推理还需要 PyTorch 和默认检查点。

在项目根目录创建环境并安装依赖：

```powershell
py -3.10 -m venv .venv-sustain-cluster
.\.venv-sustain-cluster\Scripts\python.exe -m pip install -r .\references\external_repos\sustain-cluster\requirements.txt
.\.venv-sustain-cluster\Scripts\python.exe -m pip install -e ".[research,test]"
```

当前研究环境验证版本为 Python 3.10.11、NumPy 1.26.4、Pandas 2.2.3、SciPy 1.15.3、PyTorch 2.7.0+cpu、PyArrow 19.0.1、PyYAML 6.0.2、Pytest 8.3.5、Gymnasium 1.0.0。

## 2. 准备并定位 SustainCluster

先下载只读参考仓库并固定到当前验证提交：

```powershell
git clone https://github.com/HewlettPackard/sustain-cluster.git .\references\external_repos\sustain-cluster
git -C .\references\external_repos\sustain-cluster checkout 3f6ea95cb835b89ba50b0ef76d66d14b8037643e
```

本项目不会修改或提交该仓库。程序按以下优先级查找 SustainCluster：

1. 命令行 `--sustaincluster-root`。
2. 环境变量 `SUSTAINCLUSTER_ROOT`。
3. 项目内默认目录 `references/external_repos/sustain-cluster`。

从其他工作目录运行时，建议显式设置：

```powershell
$env:SUSTAINCLUSTER_ROOT = "D:\path\to\sustain-cluster"
```

路径解析会检查 `configs/env/sim_config.yaml` 与 `envs/task_scheduling_env.py`。参考仓库缺失时，CLI 会给出中文错误和已检查目录。

## 3. 准备 workload

固定 SustainCluster commit 已跟踪预处理归档：

```text
references/external_repos/sustain-cluster/data/workload/alibaba_2020_dataset/result_df_full_year_2020.zip
```

使用主项目脚本提取并校验最终文件：

```powershell
.\.venv-sustain-cluster\Scripts\python.exe .\scripts\prepare_workload.py
.\.venv-sustain-cluster\Scripts\python.exe .\scripts\prepare_workload.py --check
```

最终 `.pkl` 大小为 `142336499 bytes`，SHA256 为 `3ba8a8e0067288f8d2542752a292f7da04cb79305689ba145cc6060e96cb7f2e`。脚本还会先校验上游 ZIP；数据来源、归档校验值、团队外部文件和许可边界见 [数据准备说明](数据准备说明.md)。不要把大型 workload 加入主项目 Git。

## 4. checkpoint 与 expert dataset

默认 BC 检查点：

```text
artifacts/sustaincluster_imitation/bc_actor_seed_11.pt
```

该文件由本项目 `reports/sustaincluster_imitation/train_bc.py` 和 `src/sustaincluster_imitation/bc_trainer.py` 生成，训练配置为 `configs/sustaincluster_imitation/bc_train.yaml`，主训练数据变体为 `deployable_baseline_forecast`。checkpoint 内嵌元数据显示 seed 11、feature dimension 233、五个语义数据中心和 validation loss `0.18717402264055813`；文件大小为 `517589 bytes`，SHA256 为 `124a86cce281c834b45e3a734015ec5fa79520babc7c19d01fd167993a5f64ab`。

这是本项目从随机初始化训练得到的行为克隆产物，不含第三方预训练模型权重。Demo 只做推理，不修改文件。团队私有协作可以保留该冻结产物；公开发布前仍需由项目负责人结合 SustainCluster 与 workload 数据许可确认，不能据此推断可自由商用。

已生成专家数据默认位于：

```text
data/processed/sustaincluster_expert/
```

其下包含 `deployable_no_future`、`deployable_baseline_forecast`、`oracle_upper_bound` 和 split manifest。大型 Parquet 不进入 Git；新开发者若要继续训练，应从团队共享存储取得同一数据版本，或按 `reports/sustaincluster_imitation/generate_expert_dataset.py` 复现。`oracle_upper_bound` 不得进入主训练集。

## 5. 最小闭环演示

MPC 演示使用 Architecture A 的 H=4 离线专家接口：

```powershell
.\.venv-sustain-cluster\Scripts\python.exe .\scripts\run_sustaincluster_demo.py --policy mpc --steps 5
```

BC 演示加载 `artifacts/sustaincluster_imitation/bc_actor_seed_11.pt`，只做在线推理：

```powershell
.\.venv-sustain-cluster\Scripts\python.exe .\scripts\run_sustaincluster_demo.py --policy bc --steps 5
```

`--steps` 只允许 5 到 20。两个入口都不会训练模型、生成专家数据或修改检查点。正常输出包含闭环步数、任务动作数、平均决策时延、求解失败数、非法动作数和资源越界数。

可选参数：

```powershell
.\.venv-sustain-cluster\Scripts\python.exe .\scripts\run_sustaincluster_demo.py `
  --policy bc `
  --steps 10 `
  --seed 9191 `
  --start-time 2023-08-01T05:00:00Z `
  --sustaincluster-root D:\path\to\sustain-cluster `
  --checkpoint D:\path\to\bc_actor.pt
```

## 6. 运行测试

推荐入口：

```powershell
.\.venv-sustain-cluster\Scripts\python.exe .\scripts\run_tests.py
```

等价命令：

```powershell
$env:PYTHONPATH = "$PWD;$PWD\src"
.\.venv-sustain-cluster\Scripts\python.exe -m pytest -q
```

`pyproject.toml` 将测试收集限制在 `tests/` 和 `reports/sustaincluster_mpc/`，不会递归收集外部参考仓库、数据目录、模型产物或 PPT 临时文件。clean clone 当前参考结果为 `139 passed, 1 skipped`；跳过项是未纳入 Git 的可选专家数据 `data/processed/sustaincluster_expert/split_manifest.json` 隔离检查，不是缺失的运行依赖。

## 7. 配置入口

- `configs/sustaincluster_mpc/h4_expert.yaml`：默认 H=4 MPC 专家。
- `configs/sustaincluster_mpc/h1_expert.yaml`：H=1 对照基线。
- `configs/sustaincluster_imitation/dataset.yaml`：专家数据变体与按 seed 互斥划分。
- `configs/sustaincluster_imitation/bc_train.yaml`：已冻结的 BC 训练配置。
- `configs/sustaincluster_imitation/sac_warm_start.yaml`：历史 SAC 复现配置，不是当前默认路线。

## 8. 常见问题

**提示找不到 SustainCluster**：检查 `SUSTAINCLUSTER_ROOT` 是否指向仓库根目录，而不是其父目录。

**BC 提示找不到检查点**：确认 `artifacts/sustaincluster_imitation/bc_actor_seed_11.pt` 存在，或用 `--checkpoint` 指定文件。

**workload 缺失**：运行 `scripts/prepare_workload.py`；它会使用固定上游 ZIP 或 `SUSTAINCLUSTER_WORKLOAD` 指定的团队文件，并拒绝错误校验值。不要把路径改成本机硬编码。

**expert dataset 缺失**：MPC/BC Demo 不需要专家数据；只有复现训练时才需要准备 `data/processed/sustaincluster_expert/`。

**Windows 路径**：PowerShell 路径建议加双引号；环境变量应指向 SustainCluster 根目录；不要在 YAML 中写用户目录绝对路径。

**从其他目录运行失败**：使用脚本绝对路径并设置 `SUSTAINCLUSTER_ROOT`。项目根目录由脚本位置和 `pyproject.toml` 自动识别。

**不要做什么**：不要修改或提交 `references/external_repos/sustain-cluster`，不要把 `data/processed/`、批量实验 JSON/CSV、其他模型检查点或虚拟环境加入 Git。
