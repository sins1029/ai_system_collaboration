# Architecture A 架构冻结决策

审计日期：2026-08-27

## 决策

默认主路线冻结为 Architecture A：

1. H=4 滚动时域 MPC 作为离线专家和性能基准。
2. 专家决策写入按 seed/episode 隔离的数据集。
3. 行为克隆策略作为当前在线直接调度器。
4. 后续强化学习只能在同一语义动作接口上增加明确正则和回退约束。

Architecture B 仅保留“BC 语义决策 → 可选事件校正 → 动作适配器”的扩展位置，不实现触发器和在线 MPC。Architecture C 只保留研究议题。

## 直接证据

- H=4 已完成实验中不可行、非法动作、资源越界均为 0。
- H=4 对 H=1 的优势主要出现在容量释放和部分前瞻状态；普通/高负载下两者接近，因此 H=4 的角色被限定为专家与基准，不夸大普适收益。
- 主专家数据：80 回合、7680 步、256125 个任务动作、求解失败 0；训练/验证/测试 seed 互斥，oracle 单独隔离。
- BC 离线聚合：accuracy 0.969809、top-2 0.996219、defer F1 0.999914、assign accuracy 0.904918、migration F1 0.947896。
- BC 真实闭环：5 个新 seed，SLA 违约均值 1552.8；H=4 为 1552.6。BC 平均决策 4.076 ms，H=4 为 20.513 ms；两者非法动作和资源越界均为 0。
- vanilla SAC 在 BC 初始化后继续更新会降低奖励、SLA 和专家一致性，不能作为当前默认路线。

## 本次最小可用验证

- 根目录受控测试：140 passed。
- 5 步 MPC：157 个任务动作，平均决策 10.689 ms，失败/非法/越界均为 0。
- 5 步 BC：157 个任务动作，平均决策 5.139 ms，失败/非法/越界均为 0。
- 从项目外目录通过 `SUSTAINCLUSTER_ROOT` 启动 BC：通过，平均决策 4.027 ms。

## 不在本次范围内

- 不新增实验。
- 不继续 SAC 训练。
- 不实现事件触发规则。
- 不重写 SustainCluster 上游源码。
- 不承诺 Architecture C 的高层动作或分层价值函数。

结论：现有证据没有推翻 Architecture A，架构冻结成立。
